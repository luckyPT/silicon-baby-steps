# 开发验收记录

2026-10-22，Node.js 24.19。独立安装 `npm ci`、11 项算法测试、全部媒体 SHA-256 校验、TypeScript 检查和生产构建均通过。`bash -n start.sh` 通过。Docker 和 Windows 脚本未在本环境执行。

## 浏览器交互验收

- 首页包含 9 集课程、两部分筛选和搜索；搜索 RRT 返回第 07、08、09 集。
- 第 09 集视频加载为可播放状态（473.17 秒），点击播放后实际播放进度推进至 21.95 秒，无媒体错误。文章首部提供完整视频和下载入口。
- 第 02 集默认地图、八邻接、启发权重 1：A* 展开 142 节点，Dijkstra 展开 556 节点，路径成本均为 35.31。
- 第 03 集默认限速限加速度方案：4.00 米，10.50 秒，到站速度和转速均为零。
- 第 06 集关节姿态与配置空间同步；整段连接使用保守几何检查。端点安全但中间碰撞的回归案例由算法测试覆盖。
- 第 09 集三维空间默认种子 7、1200 次迭代预算：RRT* 最佳成本 8.28 米、首次解在第 182 次迭代；RRT-Connect 成本 11.34 米、首次解在第 71 次迭代。两者的停止条件在界面分别标注。
- 相机平移模式实测：拖动后目标由 (0.1500, 0.3500, 0.1000) 变为 (-0.1260, 0.0614, 0.4814)；重置恢复。三维区域右键菜单被阻止。右键与左键平移模式共用 OrbitControls 的 PAN 实现；浏览器工具不提供右键拖动事件，未将左键平移验证描述成直接完成了右键拖动实测。

本次云端浏览器不能创建 WebGL 上下文，因此实际页面截图使用自动 SVGRenderer 回退，仍投影同一套三维场景并接受相机操作。WebGL 渲染路径已通过类型检查与生产构建；截图不是预录动画。真实设备优先使用 WebGL。

## 参考结果的边界

固定种子的单次结果用于复现实验，不代表算法总体排名。网站交互按采样迭代预算运行；原视频部分实验按整段运动验证次数预算，两者不等同。DWA 实验为教学仿真，不构成真实机器人执行保证。
