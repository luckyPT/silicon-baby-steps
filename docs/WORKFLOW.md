# 硅宝课程工作流

## 角色与课程

硅宝是碳硅共鸣001号员工，专注规划算法；系列《硅基学步》。01—05为移动机器人，06—11为机械臂配置空间、采样规划与后处理，12—14为时间参数化与关节约束验收。长期九部分知识路线与视频分部区分。

## 交付与发布

每章保留文章、完整视频、实验演示和对比。后续头条号不再新发配套文章，Git讲义仍维护。既有文章与已发布视频不重复发布。视频发布、Git提交、主站部署分别记录并核验。

## 音画约定

横屏1920×1080、30fps，真实三维场景与运镜，模型、曲线共用时间状态。开头约5秒寒暄，宇宙或黑洞科技背景、粒子聚合硅宝、短翻转入场。配音沿用zh-CN-YunxiNeural，rate +12%、pitch +8Hz，Rhubarb口型和动作。

封面突出硅宝形象与主题关键词，文字完整、上下各10%留白。保留16:9、4:3、3:4版本按平台版式选择。原创、首发、收益与赞赏仅在实际可用且符合条件时开启，如实声明AI生成内容。

## 验证

修改路径后重新检碰和检查关节范围。区分关节空间长度、末端距离、进度速度与关节速度，标明预算、单位和限制。统一时间伸缩不等于消除曲率接缝，也不是动力学或硬件安全验收。

## 文章配图

讲义在相关概念、操作或结论后插入中文图解并给出图注，避免把配音稿直接作为纯文字正文、或把所有插图集中放在文末。技术图采用真实模型、原始日志和核验数值，标清单位、比较条件与适用范围。第10—14集图解由 `scripts/illustrate-articles-10-14.py` 生成。
