# PRM / Lazy PRM：先修路，再按需验路

## PRM为什么分建图与查询

在静态环境中，预先采样有效配置并保存局部连通关系，得到G=(V,E)。每次新任务只把起终点接入路网，再进行图搜索。本例的规划状态q=(x,y)，三维只是显示方式；机械臂的节点应是整组关节角。总成本必须包含建图与所有查询，不能只计查询阶段。


## 采样、近邻、局部验证

本例保留180个有效随机点，各选10个最近邻，取无向候选边的并集。距离为欧氏距离d(q_i,q_j)=||q_i-q_j||。k=10是实验参数，不是算法固定要求。

局部连接器q(λ)=(1-λ)q_i+λq_j，0≤λ≤1。两端有效不代表整段有效。

本例障碍是已经膨胀的圆盘。线段a→b到圆心c的最近参数：

λ*=clip_[0,1](((c-a)·(b-a))/||b-a||²)。

先投影到直线，再把参数限制在线段上。最近点p*=a+λ*(b-a)。只有||p*-c||大于膨胀半径R才有效；边界相切算碰撞。代码额外使用1e-8的数值余量；退化线段按点的距离处理。机械臂需要匹配几何和运动模型的整段验证。


## 查询与路径成本

新起终点各连接10个近邻，每次新增20条候选接入边；查询完成后移除临时顶点及边，基础路网保留。

w_ij=||q_i-q_j||，J(π)=Σw_ij。Dijkstra在更小的g(u)+w(u,v)出现时更新g(v)和父节点，最后回溯路径。固定图上最短不等于连续空间最短。


## Lazy的状态与失败处理

未知：尚未检查；有效：已验证通过；无效：已验证碰撞。

先在候选图中搜索；沿候选路径检查未知边，缓存有效结果。遇到第一条无效边就移除它，重新搜索，直至整条返回路线都验证通过。无候选路径时只能报告当前图失败，或按预设预算补采样，不能把未知边直接交给机器人执行。

本集教学变体先验证点，只延迟边检测；原始Lazy PRM还可以延迟节点验证。

手算三角图S=(0,0)、A=(1,0)、G=(1,1)，障碍圆心(0.5,0.5)、半径0.18。先选择长度√2的直连，但中点碰撞；删边后选择S→A→G，长度2。两种方法最终都检查三条边，这个小图没有节省检测。


## 真实实验对照

静态二维点机器人；障碍圆心(1.6,-0.65)、(2.55,0.75)、(3.65,-0.55)，膨胀半径0.45、0.50、0.45。三次查询起终点为(0,-1.7)→(5,1.5)、(0,1.7)→(5,-1.7)、(0,0)→(5,0)。

同一随机种子下，两种方法共用采样点、候选边、起终点和边长成本。基础边验证结果可跨查询复用，临时起终点接入边不会错误复用。

种子17：PRM基础1040次+三次各20次=1100次；Lazy新增11、13、9次，累计33次。

种子1：1102 vs 32；种子7：1106 vs 42。

统计口径为整条线段的碰撞检测调用，不包括点检测、图搜索或其他操作，不等同于运行时间。返回路径均逐段复检；相同固定候选图下最终长度一致。

种子17第二次查询第一条候选包含无效边(82,141)，删边后重搜，最终长度约6.479m。保留完整原始日志，不只展示成功结果。


## 边界

有限图失败不构成连续空间无路证明。某区域单次命中概率p，N次独立采样均漏掉它的概率为(1-p)^N；这不是整条路线的连通性证明。

障碍、机器人、夹爪或负载几何变化时，验证缓存须失效或重新确认。

几何路径还需时间参数化、关节约束与控制执行；本集没有真机执行。

## 在交互实验室亲自试一遍


本页实验采用同一静态二维点机器人和膨胀圆盘，直接在浏览器计算候选图、Dijkstra 搜索与逐条线段检碰；播放只是刚刚计算出的验证日志回放，不是预录演示。


1. 固定种子，把近邻数 k 从 10 降到 1：路网可能断开。失败只说明这个有限图没有路径，不证明连续空间无路。

2. 选第二次查询，单步观察未知边如何变成有效或无效；遇到无效边后重新搜索，未检完的金色候选不能执行。

3. 依次看三次查询，比较累计检碰。基础边缓存复用，临时起终点接入边每次重新验证。

4. 修改 N、k 或种子会重新建图并清空缓存。重置回放只重置当前日志播放，不改变算法结果。


浏览器使用 Mulberry32 随机数，原始 Python 使用 NumPy 随机数；**同种子不代表跨实现相同采样点**，不能拿本页数字冒充视频中的 1100/33。公平对照是每次运行中两种算法共用同一图，且最终路径成本一致、全段验证通过。计数不包括有效点采样、图搜索与独立最终复检，不是耗时排名。
